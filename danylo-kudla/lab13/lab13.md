## Хід роботи

1. Структурні шаблони - це шаблони проєктування, які відповідають за те, як збирати класи та об'єкти у більші, складніші структури, зберігаючи структури гнучкими та ефективними.
2. Міст - це спосіб організації коду, який розділяє абстракцію та реалізацію на дві незалежні частини.
<br>Приклад реалізованого моста на основі пульта та просторою [lab13](lab13.py).

```mermaid
---
title: UML-діяграма класів з реалізацією патерну "міст" для пульта та присторою
---
classDiagram
    class Device {
        <<interface>>
        +turn_on()
        +turn_off()
        +set_channel(channel)
    }
    
    class TV {
        +turn_on()
        +turn_off()
        +set_channel(channel)
    }
    
    class Radio {
        +turn_on()
        +turn_off()
        +set_channel(channel)
    }
    
    class RemoteControl {
        #device: Device
        +power_on()
        +power_off()
        +channel(number)
    }
    
    class AddRemoteControl {
        +mute()
    }
    
    %% Зв'язки
    RemoteControl o--> Device : 
    RemoteControl <|-- AddRemoteControl : 
    Device <|.. TV : 
    Device <|.. Radio : 
```
## Висновок
У підсумку виконання лабораторної роботи ознайомився з сімома патернами, а саме: адаптер, міст, компонувальник, декоратор, фасад, легковаговик, замісник. На практиці реалізовано патерн "міст" з реалізацією роботи пульта та пристрою, що дало змогу розділити клієнтський інтерфейс та внутрішню реалізацію з можливістю гнучкої підтримки.
