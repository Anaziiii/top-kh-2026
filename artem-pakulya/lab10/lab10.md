# Лабораторна робота №10

## Хід роботи

1. Створено клас Cat із прихованим атрибутом _age.

2. За допомогою декоратора @property реалізовано метод для безпечного отримання значення віку (getter).

3. Реалізовано метод-setter (@age.setter), який встановлює нове значення віку та містить логіку валідації (захист від введення від'ємних чисел).

4. Реалізовано метод-deleter (@age.deleter) для обробки операції видалення властивості об'єкта.

5. Протестовано роботу всіх методів: успішне зчитування, зміну даних із перевіркою та їх видалення за допомогою оператора del.

## Висновки
Під час виконання лабораторної роботи я навчився використовувати декоратор @property для створення властивостей об'єкта. Також я практично ознайомився з концепцією інкапсуляції, реалізувавши getter, setter та deleter для безпечної роботи з даними класу.
