# Лабораторна робота №9

## Хід роботи

1. Створено клас Cat з атрибутом віку.

2. Реалізовано перевизначення поведінки базових методів (зокрема, змінено стандартну поведінку методу __str__, який неявно успадковується від системного класу object і зазвичай виводить адресу в пам'яті).

3. До класу додано магічні методи для перевантаження операторів:
__eq__ — для перевантаження оператора порівняння ==.
__add__ — для перевантаження оператора додавання +.

## Висновки
Під час виконання лабораторної роботи я навчився перевизначати стандартну поведінку методів та реалізував магічні методи (__str__, __eq__, __add__) для перевантаження стандартних операторів у Python.
