# Лабораторна робота №6

## Хід роботи

1. У файлі lab6.py модифіковано клас Cat: метод __init__ приймає аргументи name, breed, age. Також додано змінну класу та лічильник об'єктів.

2. Клас містить метод information, що повертає словник з даними кота, та окремий метод для виводу змінної класу.

3. Створено екземпляри animal1, animal2, які передають дані в __init__ та автоматично збільшують лічильник при створенні.
