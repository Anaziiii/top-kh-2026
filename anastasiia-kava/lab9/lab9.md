**Мета роботи** - засвоїти застосування принципу поліморфізму в об’єктно-орієнтованому програмуванні.

1. Застосовано декоратори `@property` для атрибута ціни. Створено геттер для читання, сеттер для захисту від запису від'ємних значень та обчислювану властивість для автоматичного конвертування ціни у долари
2. Реалізовано метод `__gt__` (greater than), що дозволило використовувати стандартний математичний оператор > для порівняння двох об'єктів Phone за їхньою ціною, а також інші методи як Реалізовано метод `__add__,` який дозволяє додавати два об'єкти (оператор +) і повертати новий екземпляр
3. У класі Techno створено метод test(other), який приймає як аргумент екземпляри інших класів. Це дозволило продемонструвати здатність викликати методи переданого об'єкта незалежно від його точного класу.
