**Мета роботи** – освоїти роботу з декораторами в Python 3

## Хід роботи:

У ході виконання лабораторної роботи було вивчено використання декоратора @property у Python.
Реалізовано механізм getter, setter та deleter для атрибута price, що дозволяє контролювати доступ до приватних даних об’єкта.
Також реалізовано інкапсуляцію даних за допомогою прихованих атрибутів \_price та \_address.

## Висновок

Було засвоєно принцип роботи декораторів у Python та їх застосування для контролю доступу до даних класу.
