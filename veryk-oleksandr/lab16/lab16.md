## Хід роботи

### 1. Види тестування та піраміда тестування

Тестування програмного коду — це процес перевірки програми для виявлення помилок і підтвердження правильності її роботи.

Основні види тестування:

- **Unit-тестування** — перевірка окремих функцій, методів або класів.
- **Інтеграційне тестування** — перевірка взаємодії між окремими частинами програми.
- **Системне тестування** — перевірка роботи всієї програми як єдиного цілого.
- **Приймальне тестування** — перевірка відповідності програми вимогам користувача.

Піраміда тестування показує, як доцільно розподіляти тести в програмному проєкті. В її основі знаходяться численні unit-тести, вище — інтеграційні тести, а на вершині — невелика кількість системних або автоматизованих користувацьких тестів.

### 2. Unit-тестування за допомогою unittest

Для практичної частини роботи використав вбудований модуль Python `unittest`, який дозволяє створювати та виконувати автоматизовані тести.

Для прикладу створив клас `MediaContent`, який зберігає назву та рік випуску медіаконтенту, дозволяє додавати оцінки та обчислювати середній рейтинг.

Було написано чотири тести:

1. Перевірка правильності початкових даних об'єкта.
2. Перевірка додавання оцінки.
3. Перевірка обробки некоректної оцінки.
4. Перевірка правильності обчислення середнього рейтингу.

Для запуску тестів використав команду:

```bash
python -m unittest -v
```
