ТЕМА 16. Тестування програмного коду

Мета роботи: ознайомитися із техніками тестування програмного коду.

Виконання завдання

1. Види тестів та піраміда тестування

Піраміда тестування показує правильне співвідношення різних видів автоматичних тестів у проєкті (від основи до вершини):

Unit-тести (Модульні) — база піраміди. Перевіряють окремі маленькі частини коду (функції або методи класу) ізольовано від інших. Вони дуже швидкі.

Integration-тести (Інтеграційні) — середина піраміди. Перевіряють, як декілька різних модулів або класів працюють разом (наприклад, взаємодія коду з базою даних).

E2E-тести (End-to-End / Наскрізні) — вершина піраміди. Перевіряють роботу всієї системи цілком, імітуючи дії реального користувача у програмі чи браузері.

2. Написання unit-тесту на Python 3 (модуль unittest)

Підключено модуль unittest та створено цільовий клас Calculator із методами додавання add() та ділення divide() (з перевіркою ділення на нуль).   
Створено тестовий клас TestCalculator, успадкований від базового класу unittest.TestCase.
Реалізовано метод setUp() для автоматичної ініціалізації об'єкта калькулятора перед кожним тестом.
Написано модульні тести test_add(), test_divide() (з використанням assertEqual) та test_divide_by_zero() (з використанням assertRaises для перевірки виключення ValueError) і запущено їх виконання через unittest.main().   

Висновок: У ході роботи я вивчив рівні піраміди тестування (Unit, Integration, E2E) та навчився створювати й запускати автоматичні модульні тести мовою Python 3 за допомогою вбудованої бібліотеки `unittest`.
